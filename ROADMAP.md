### ⚠️ Пять ловушек в данных (сильный слайд для К2 и К7)
1. **`biopsed`**: все раки подтверждены биопсией, поэтому `biopsed=False` всегда означает доброкачественное поражение. Колонка исключена (`NEVER_USE` в `config.py`).
2. **Пустые анкеты**: у 804 снимков пусты 13 клинических полей, и **все 804 доброкачественные**. Основной эксперимент проводим только на признаках, которые заполнены у всех (`SAFE_*` в `config.py`). Полные анкеты проверяем отдельно, на подвыборке из 1467 снимков.
3. **Дубликаты с конфликтом меток**: 15 пар одинаковых фото, в 12 из них диагнозы разные. Удалено 27 снимков. Подтверждение: Pedersen et al., 2025 (arXiv:2504.11415, раздел 3.1), авторы датасета подтвердили, что это ошибки.
4. **`lesion_id` не уникален между пациентами** (250 значений). Поражение однозначно определяется парой `patient_id` + `lesion_id`, а делим мы по `patient_id`.
5. **`UNK` в симптомах**: у `grew`/`changed` значение «неизвестно» в 351 случае из 400 означает рак (артефакт сбора данных). Поэтому `UNK` считаем пропуском и заполняем самым частым значением из train, без отдельной категории (`features.py → clean()`).

🎓 *Объяснить:* что такое data leakage и shortcut learning; почему делим по пациентам, а не по фото; что такое md5.

- [ ] **5.1 Late fusion** (локально, несколько секунд):
  ```
  python src/late_fusion.py --image-model image_efficientnet_b0
  ```

**Как устроена мультимодальная модель** (`src/models.py → LesionNet`):
```
фото 224×224 → EfficientNet-B0 (предобучена на ImageNet) → 1280 чисел → Linear → 128 ┐
анкета (возраст, место, 6 симптомов) → one-hot/масштаб → 22 числа → Linear → 32 ─────┴ concat 160 → Linear → вероятность рака
```

**Настройки обучения** (все в `train_image.py`, их нужно перечислить в отчёте):
- AdamW, learning rate 1e-4 для CNN и 1e-3 для головы, cosine schedule;
- до 25 эпох, early stopping через 6 эпох без роста val AUC;
- batch 32, BCE loss с `pos_weight`;
- аугментация: crop, отражения, поворот, яркость и контраст.

🎓 *Объяснить:*
- **transfer learning** (сеть уже умеет видеть края и текстуры по ImageNet, мы доучиваем);
- **почему у CNN маленький learning rate** (не «сломать» предобученные веса);
- **зачем аугментация** (данных мало);
- **early fusion, late fusion и feature fusion**: в чём разница;
- **что такое epoch, batch, loss, overfitting.**

## Этап 9. Ответственный AI [К7]

Раздел в отчёте и 1–2 слайда. **Каждый риск сопровождай конкретной мерой:**

| Риск | Мера |
|---|---|
| Bias: мало тёмных типов кожи (типы 5–6 представлены 11 снимками) | анализ по подгруппам, предупреждение в демо, нужны данные других популяций |

| Ошибки разметки в датасете | нашли через md5 и удалили 27 снимков; остальная разметка тоже может быть неидеальной |
| Мало меланом (52), самого опасного рака | бинарная задача как основная, метрики по диагнозам, ограничение раскрыто |
| Одна клиника, одна страна, свои камеры | нужна внешняя валидация (HAM10000 / ISIC) |
| Злоупотребление: самодиагностика | только триаж, дисклеймер, нужна клиническая валидация и регуляторная сертификация |
